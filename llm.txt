# Hautezelle Studio Project Context

## 1. Project Overview
Hautezelle Studio is a premium web application for a leading Nigerian resin art and craft enterprise. The site serves as an e-commerce platform, an educational hub (The Academy), and a portfolio for bespoke services.

**Core Objectives:**
- Showcase luxury resin art products (Frames, Jewelry, Decor).
- Promote educational programs (Foundation, Masterclass, Business of Art).
- Facilitate bookings for services (Resin N Sip, Corporate Partnerships).
- Establish a global, sophisticated brand identity.

## 2. Tech Stack & Architecture
- **Framework:** React 19 (Client-side rendering).
- **Routing:** React Router DOM v7 with BrowserRouter (clean URLs such as /shop). Old /#/ links are redirected in index.tsx.
- **Styling:** Tailwind CSS 3 compiled at build time (tailwind.config.js, index.css).
- **Icons:** Lucide React.
- **Animations:** Framer Motion.
- **Build/Entry:** standard index.tsx/index.html structure.

## 3. Design System (Luxury Aesthetic)
- **Colors:**
  - Primary: Teal Palette (50-950).
  - Backgrounds: Slate-50, White.
  - Accents: Gold/Bronze implications via styling (though mapped to Teal/Slate).
- **Typography:**
  - Headings: 'Playfair Display' (Serif) - Elegant, high-contrast.
  - Body: 'Lato' (Sans-serif) - Clean, readable.
- **Shapes & UI:**
  - **Glassmorphism:** Used in navigation and overlays.
  - **Curvature:** Heavy use of `rounded-[2.5rem]` or `rounded-3xl` for a soft, premium feel.
  - **Spacing:** Generous whitespace (padding/margin) to convey luxury.
  - **Interactions:** Subtle hover lifts, scale effects, and smooth transitions.

## 5. SEO and GEO
- **Single source of truth:** `data/site.json` holds business facts, page titles and descriptions, products and prices, courses, services and FAQs. Edit it there and every output updates.
- **Live address:** `business.url` in `data/site.json` (currently https://hautezelle.vercel.app). Change it when a custom domain is connected.
- **Structured data:** `seo/schema.js` builds the JSON-LD graph per page (Store/LocalBusiness, WebSite, FAQPage, ItemList of Products, Course, Service, BreadcrumbList).
- **Prerendering:** `npm run build` runs `vite build` then `scripts/prerender.mjs`, which writes a full HTML page per route (shop.html, academy.html and so on) with head tags, JSON-LD and readable content, plus 404.html, sitemap.xml, robots.txt, llms.txt, llm.txt and llms-full.txt.
- **In-app:** `components/SEO.tsx` takes `page="/shop"` and keeps the head in sync during client-side navigation.
- **Vercel:** `vercel.json` uses cleanUrls, so /shop serves shop.html.
