# Hautezelle Studio Project Context

## 1. Project Overview
Hautezelle Studio is a premium web application for a leading Nigerian resin art and craft enterprise. The site serves as an e-commerce platform, an educational hub (The Academy), and a portfolio for bespoke services.

**Core Objectives:**
- Showcase luxury resin art products (Frames, Jewelry, Decor).
- Promote educational programs (Foundation, Masterclass, Business of Art).
- Facilitate bookings for services (Resin N Sip, Corporate Partnerships).
- Establish a global, sophisticated brand identity.

## 2. Tech Stack & Architecture
- **Framework:** React 19 (Client-side rendering).
- **Routing:** React Router DOM v7 (HashRouter used for compatibility).
- **Styling:** Tailwind CSS (via CDN).
- **Icons:** Lucide React.
- **Animations:** Framer Motion.
- **Build/Entry:** standard index.tsx/index.html structure.

## 3. Design System (Luxury Aesthetic)
- **Colors:**
  - Primary: Teal Palette (50-950).
  - Backgrounds: Slate-50, White.
  - Accents: Gold/Bronze implications via styling (though mapped to Teal/Slate).
- **Typography:**
  - Headings: 'Playfair Display' (Serif) - Elegant, high-contrast.
  - Body: 'Lato' (Sans-serif) - Clean, readable.
- **Shapes & UI:**
  - **Glassmorphism:** Used in navigation and overlays.
  - **Curvature:** Heavy use of `rounded-[2.5rem]` or `rounded-3xl` for a soft, premium feel.
  - **Spacing:** Generous whitespace (padding/margin) to convey luxury.
  - **Interactions:** Subtle hover lifts, scale effects, and smooth transitions.

## 5. SEO Strategy
The application uses a custom `SEO` component to inject metadata into the `<head>`:
- **Title Tags:** Format: `Page Name | Hautezelle Studio`.
- **Meta Description:** Unique for each page.
- **Open Graph:** Optimized for social sharing (WhatsApp/Twitter/LinkedIn previews).
- **Structured Data (JSON-LD):** `Organization`, `Product`, `Course`, and `LocalBusiness` schemas implemented.
